# PhysFlow · 零代码拖拽式 AI 实验数据流水线

> CCNU 第一届黑客松参赛作品 · 提交仓库
> 开发窗口：2026-10-23 00:00 — 2026-10-25 20:00（本仓库提交记录落在该窗口内）

## 一句话简介
面向高校理工科学生的**积木式实验数据处理系统**：不是"一个实验一个脚本"，而是让学生拖拽节点、连线绑定变量、自定义公式，搭建属于自己的数据处理流水线，并可保存为模板复用。

## 功能特性
- **零代码画布**：SVG 连线画布 + 侧边栏积木节点，拖拽即用，连线即绑定数据。
- **16 种积木节点**：输入（手动 / CSV / 图片识图 / 常量）、计算（自定义公式 / 统计 / 误差 / 单位转换）、AI 推理（数据判读 / 答疑 / 总结 / 拟合）、输出（预览 / Markdown 报告 / CSV 导出 / 摘要）、控制（分支 / 循环）。
- **自研表达式引擎**：递归下降解析，不使用 `eval`/`new Function`，天然防注入；支持中文变量名、`{{变量}}` 引用、数组逐元素运算。
- **拓扑执行引擎**：Kahn 拓扑排序逐节点执行，建连线时即拒绝成环；节点独立调试 / 启停 / 复制，错误局部化并中文化提示。
- **AI 双模**：内置本地规则引擎（离线 100% 稳定可演示），provider 接口可插拔，正式版一行切换真实大模型。
- **模板系统**：内置「薄透镜组」「单摆测 g」两套演示模板；用户模板存于 localStorage，复用只改输入数据即可。
- **一键导出**：Markdown 实验报告预览 / 复制 / 下载，CSV 表格一键导出到 Excel。

## 技术栈
- **前端**：纯 HTML + CSS + 原生 JavaScript（单文件、零依赖、零构建）。
- **画布**：SVG 连线渲染。
- **表达式引擎**：自研递归下降解析器（无 `eval`）。
- **存储**：localStorage（用户模板）。
- **AI**：本地规则引擎（默认）/ 可插拔 LLM provider。

## 如何运行
- **方式一（最简单）**：直接双击 `index.html` 用浏览器打开即可使用。
- **方式二（推荐，避免个别浏览器对本地文件的限制）**：在仓库目录下起本地服务器
  ```bash
  python -m http.server 8613
  ```
  然后访问 `http://127.0.0.1:8613/index.html`

## 内置演示模板
1. **薄透镜组**（比赛现场演示）：`(f1, f2, d)` → 透镜组公式（F、主点 lH/lH2）→ 相对误差 → AI 判读 → Markdown 报告。演示数据 `f1=10.98, f2=15.90, d=4.12` → F=7.67 cm，相对误差 0.92%。
2. **单摆测 g**：L + 5 组周期 → 统计（均值 / A 类不确定度）→ `g=4π²L/T̄²` → 误差合成 → AI 判读 → 报告。证明"同一系统不写一行实验专属代码"即可换实验。
